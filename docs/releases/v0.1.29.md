# obs-agent-connector v0.1.29

## Changes

- Removed token usage fields and compatibility aliases from built-in `invoke_agent` spans so workflow roots no longer duplicate model-call token statistics ([PR #28](https://github.com/GuanceCloud/obs-agent-connector/pull/28)).
- Kept attributable token usage on `llm` spans, where it continues to drive `gen_ai.client.token.usage` metrics.
- Preserved Kiro's aggregate billing credit on `invoke_agent` as `gen_ai.usage.credit` because Kiro does not expose a reliable per-call credit attribution.
- Removed Grok's root-only token aliases while retaining exact or explicitly estimated per-LLM usage.

## Upgrade notes

- Dashboards and queries should read token usage from `llm` spans or `gen_ai.client.token.usage` metrics rather than from `invoke_agent`.
- Kiro billing credit remains available on the root span and is not converted into token usage.

## Validation

- The full Go test suite, `go vet ./...`, release build, formatting checks, and documentation language checks passed before publication.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
