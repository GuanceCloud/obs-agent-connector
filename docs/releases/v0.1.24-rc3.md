- OpenClaw removal now disables an existing legacy plugin entry while preserving its configuration and files. Unrelated plugin settings are preserved.
- Retained all v0.1.24-rc2 features, including built-in OpenClaw telemetry and GenAI first response chunk spans and metrics.

Full Go tests, vet, and build passed, including regressions for removal with retained legacy directories, custom OpenClaw state roots, and legacy registration preservation. The OpenClaw runtime compatibility limits documented in v0.1.24-rc2 still apply.
