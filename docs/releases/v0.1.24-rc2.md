## Changes

- Added a built-in OpenClaw telemetry adapter with an embedded native plugin bridge, managed installation and removal, and migration from the external plugin.
- Added durable OTLP trace and metric delivery with independent signal retries and duplicate suppression.
- Added native model-call timing using `model_call_ended`. First response chunk latency is exported as the `gen_ai.response.time_to_first_chunk` span attribute and `gen_ai.client.operation.time_to_first_chunk` histogram, both in seconds, with GenAI metric attributes.
- Preserved turn-level token totals when native model calls cannot be matched to individual usage records without guessing.
- Included the terminal span status fix and all changes from v0.1.24-rc1, including built-in WorkBuddy support.

## OpenClaw migration and compatibility

Run `obs-agent-connector install openclaw` to register the built-in bridge, then restart OpenClaw to load it. Managed files are stored under `~/.obs-agent-connector/openclaw/`. Updates preserve existing configuration; legacy external configuration remains unless explicitly purged.

The installer currently requires strict JSON for OpenClaw configuration. First response chunk latency requires the runtime to emit `model_call_ended.timeToFirstByteMs`; this is not a model-server time-to-first-token measurement. Missing timing is omitted. The GenAI first-chunk conventions are currently in Development.

Validation includes Go tests, vet, race checks for telemetry components, and a local native-bridge-to-OTLP smoke test. A live OpenClaw Gateway conversation and native macOS/Windows OpenClaw execution have not been validated.
