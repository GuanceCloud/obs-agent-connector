# v0.1.32-rc12 - Supply the Hermes installer release endpoint

This prerelease builds on v0.1.32-rc11 and includes the additional installer fix from [PR #37](https://github.com/GuanceCloud/obs-agent-connector/pull/37).

## Changes since RC11

- Pass the Hermes GitHub release asset base through `OSS_ENDPOINT`, which the published installer requires even for GitHub downloads. This fixes installation and update failures reporting `OSS_ENDPOINT is required` after the installer starts.
- Configure this requirement in the Hermes Agent definition. OSS installation keeps its existing release endpoint, and other Agents keep their default environment.
- Generate shell command previews from the same environment as execution. Add coverage for GitHub/OSS release endpoints, install/update previews, and configuration-preserving updates.

Validation includes full Go tests, vet, build, and an isolated check of the published installer reaching the expected GitHub archive URL, stopping before download or installation. Existing runtime configuration remains owned by the external installer; updates retain `--no-config`.

This prerelease retains the Hermes home-directory and installer filename fixes and Codex native sandbox diagnostics from RC11. Stable release pointers are unchanged.
