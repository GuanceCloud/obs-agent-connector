# v0.1.31 — QwenWork CN telemetry

## Changes

- Add the built-in `qwenwork-cn` integration with native local Hooks, transcript
  replay, measured per-call token usage and independent trace/metric retry state.
- Export ordered Assistant outputs, evidence-backed Skill spans and optional
  thinking content. Thinking is disabled by default; content-none suppresses it.
- Add bounded, privacy-safe offline diagnostics for usage, replay and uploads.
- Preserve user configuration on updates and unrelated Hooks during installation
  and removal. Normal installation enables the native token-reporting flag.
- Support QwenWork CN discovery and installation on macOS, Linux and Windows.
- Fix Windows binary-only installation with an empty endpoint so the plugin
  download source resolves without an explicit workaround.
- Improve structured GenAI message compatibility and optional Assistant-to-LLM
  association in the shared telemetry pipeline.

## Validation and known limitations

QwenWork CN 1.2.5 on macOS ARM64 has native execution and independently queried
backend evidence for LLM usage, tool results, Assistant output and Skill parentage.
Windows AMD64 installation and single-turn collection passed user-reported smoke
testing; this is not independent backend or full lifecycle verification.

Native Linux and Windows ARM64 collection, enterprise policy, pure-generation
cancellation, provider terminal failures and nonzero reasoning-token usage remain
unverified. Platform support does not imply equivalent native acceptance.
Subagent span collection is not implemented; child usage is excluded from parent
totals. Missing usage, credits and TTFT are not estimated.

The known Agent tool-result preview issue remains tracked separately: result data
is present in OTLP/backend attributes, but the viewer preview can be blank.
See [issue 7130926248](https://project.feishu.cn/67d94b8bcb5582623a9ef7a8/67e4df4a0029e0f8957669f4/detail/7130926248)
and [product research](https://github.com/GuanceCloud/obs-agent-connector/blob/v0.1.31/docs/product-research/qwenwork-cn.md).

## Installation and upgrade

Install or update the connector binary to this version, then use
`obs-agent-connector install qwenwork-cn` for a new integration or
`obs-agent-connector update qwenwork-cn` for an existing integration.
Normal installation merges `QODERCN_EXPOSE_TOKEN_USAGE=1` into the profile dotenv;
restart the desktop worker when needed. Updates preserve existing config and
dotenv contents, including privacy choices. Process/project overrides may take
precedence over the profile flag.

The release includes six platform archives, shell/PowerShell installers, version
metadata and `SHA256SUMS`. Verify checksums before installation. This stable
release includes the Linux and Windows installer corrections made after
`v0.1.31-rc1`; the published RC tag and assets remain unchanged.
