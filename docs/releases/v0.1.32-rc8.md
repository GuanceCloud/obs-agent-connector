# v0.1.32-rc8 - Native Codex Tool identity correlation

This prerelease updates [PR #35](https://github.com/GuanceCloud/obs-agent-connector/pull/35), which remains open and unmerged. Stable release pointers are unchanged.

## Changes since RC7

- Prefer the runtime-injected native session and Tool call ID, then resolve the Hook session/turn/call triple to the actual successfully exported OBS Trace ID and Tool Span ID. Log evidence is explicitly labeled `native_process_tool_id` with observed confidence. An unmatched native Tool ID never falls back to command guessing. Legacy unique command correlation remains explicitly inferred.
- Read context from the verified namespace-init or direct command child. Child metadata requires matching ownership, parent/start identity, namespace identities and exact command digest. Conflicting contexts remain unlinked. Raw environment, command and output contents are not persisted.
- Enrich already-discovered instances when command context arrives later, trigger reconciliation when metadata changes, and permit pending association to complete after sandbox exit.
- Existing installation/update reconciliation registers SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop and Interrupt when sandbox collection is enabled. Run `update codex` to repair missing registrations without changing endpoint/authentication or other runtime settings. Stop-only registration cannot supply the required Tool/turn context.

## Validation

Full Go checks and regression tests cover native Tool ID precedence, identical commands, mismatched/ambiguous context, child isolation boundaries, late enrichment and terminal association. An opt-in real-host test runs two concurrent actual Codex 0.163.0 CLI sessions against a local deterministic model fixture and protobuf receiver. Codex itself produces Hooks, session/turn identities and transcripts; the fixture supplies identical command call IDs in the separate sessions. Two sandbox bindings must match their own exported OBS Tool spans and distinct Traces. No Hook payload, native identity, sandbox event or transcript is injected. The earlier helper-only test remains a narrower fixture.

Automatic collection remains Linux PID-namespace polling and can miss very short executions. Exact creation/destruction clocks remain unknown and omitted. Missing historical context is not reconstructed. Independent product navigation and remote/macOS/Windows collection remain outside this change.
