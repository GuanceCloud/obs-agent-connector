# obs-agent-connector v0.1.32-claude-desktop-rc2

## Changes

- Fixed Windows `claude-desktop` installation when Local AppData fails the
  safety checks for staging the administrator helper. OBS tries the current
  account's profile folder with the same path and permission checks.
- Added a protected access control list to the helper's temporary directory.

## Scope and validation

- This prerelease covers machine-level Hooks for local Code and Cowork on
  macOS, Linux, and Windows.
- The Windows release pipeline passed regression tests for the staging fallback,
  access controls, and helper pinning.
- On the target device, verify native Hook loading and Guance ingestion by
  sending one request in each of two new sessions, one in local Code and one in
  Cowork. Confirm one trace per session in the Guance test workspace.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.

For a Windows RC1 retest, run the RC2 installer in PowerShell as the account that
uses Claude Desktop. Use `-BinaryOnly` to reuse the existing telemetry destination
and tags.

```powershell
$tag = 'v0.1.32-claude-desktop-rc2'
$base = "https://github.com/GuanceCloud/obs-agent-connector/releases/download/$tag"
$setup = Join-Path $env:TEMP 'obs-claude-desktop-rc2-install.ps1'
Invoke-WebRequest -UseBasicParsing -Uri "$base/install.ps1" -OutFile $setup -ErrorAction Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $setup `
  -Version $tag -DownloadBaseUrl $base -BinaryOnly
if ($LASTEXITCODE -ne 0) { throw 'The RC2 installer failed.' }
```

Use the installed executable to confirm RC2, register the Hook, and check the
machine registration. Approve the Windows UAC prompt when it appears.

```powershell
$obs = Join-Path ([Environment]::GetFolderPath('LocalApplicationData')) `
  'Programs\obs-agent-connector\bin\obs-agent-connector.exe'
& $obs version --offline
& $obs install claude-desktop --capture-content none
& $obs status claude-desktop
```
