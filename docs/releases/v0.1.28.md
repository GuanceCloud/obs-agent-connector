# obs-agent-connector v0.1.28

## Changes

- Prevented Windows installer tags such as `-Tag "user_id=user-123,user_name=Guance"` from being silently stored as one `global_tags` entry. Ambiguous comma-joined assignments now fail with guidance instead of producing missing telemetry attributes ([issue #25](https://github.com/GuanceCloud/obs-agent-connector/issues/25), [PR #26](https://github.com/GuanceCloud/obs-agent-connector/pull/26)).
- Preserved distinct tags and non-ASCII values when tags are supplied as a PowerShell array, for example `-Tag @("user_id=user-123", "user_name=Guance", "env=prod")`. Commas remain supported inside a single tag value when they do not introduce another assignment.
- Added Go config-merge tests and a Windows PowerShell installer contract test in CI.

## Upgrade notes

- Update the connector before retrying installation with a tag array. The installer does not automatically repair an existing `config.json` that already contains a single comma-joined `global_tags` entry; reinstall with distinct `-Tag` arguments or correct that entry separately.
- The integration UI that generates installation commands should emit separate array entries for each tag. A comma-joined command will now fail visibly until its generator is corrected.

## Validation

- The full Go test suite, `go vet ./...`, and release packaging passed. Windows PowerShell tag validation passed in the CI workflow for the merged fix.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
