# v0.1.32-rc11 - Fix Hermes GitHub installer downloads

This prerelease builds on v0.1.32-rc10 and includes the installer fix from [PR #37](https://github.com/GuanceCloud/obs-agent-connector/pull/37). It retains the Hermes home-directory support and Codex native sandbox observation and Hook diagnostics from RC10.

## Changes since RC10

- Download the published `install.sh` asset for Hermes GitHub installation and updates, fixing HTTP 404 errors caused by requesting the nonexistent `install-release.sh` asset.
- Allow Agent definitions to customize the Unix GitHub installer filename. Other Agents keep the default `install-release.sh`; OSS installation continues to use `install.sh`.
- Add regression coverage for Hermes GitHub and OSS installer URLs, exact Release URLs, and the default GitHub installer filename.

The external Hermes installer continues to own runtime configuration. Updates preserve existing configuration with `--no-config`. This prerelease does not change stable release pointers.
