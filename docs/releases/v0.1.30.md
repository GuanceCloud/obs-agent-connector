# obs-agent-connector v0.1.30

## Changes

- Added complete `CODEX_HOME` support for Codex installation, update, discovery, automatic Hook trust, runtime state, legacy configuration, Skill classification, and removal ([PR #30](https://github.com/GuanceCloud/obs-agent-connector/pull/30)).
- Preserved `~/.codex` as the default when `CODEX_HOME` is unset.
- Kept connector-managed configuration and Hook logs under `~/.obs-agent-connector/codex` while Codex-owned files follow `CODEX_HOME`.

## Upgrade notes

- Existing `$CODEX_HOME/gtrace.json` files remain readable as a legacy migration source. The connector-managed `~/.obs-agent-connector/codex/gtrace.json` takes precedence when present.
- A normal `remove codex` preserves legacy Agent-local configuration. Use `remove codex --purge-config` to delete that configuration and connector upload state, or pass `--enable` during installation to explicitly enable telemetry.

## Validation

- Regression tests cover custom `CODEX_HOME` installation, trust, discovery paths, runtime configuration and state, Skill source classification, and cleanup.
- The full Go test suite, `go vet ./...`, release build, pull-request CI, package smoke tests, and Windows Hook smoke tests passed before publication.
- The stable release uses the same connector code validated in `v0.1.30-rc1`.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
