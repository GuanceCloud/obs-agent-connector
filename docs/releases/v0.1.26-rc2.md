# obs-agent-connector v0.1.26-rc2

## Changes

- Added `mimo` as a built-in Agent with discovery and full external-plugin lifecycle support.
- Added exact GitHub plugin release URLs for prerelease validation. `plugin_source=github` can now use a complete `.../<plugin>/releases/download/<tag>` base, allowing `obs-agent-connector install mimo` to download the MiMo plugin RC automatically.
- Preserved the stable GitHub behavior where an organization base resolves each plugin from `releases/latest`.

## Scope and validation

- MiMo Code 0.1.14 was validated with `xiaomi/mimo-v2.5`, including a two-step model flow with a `read` tool call and non-empty structured input on the second LLM span.
- The Windows installer and its nested archive download both stay pinned to the exact plugin RC, while Unix resolves the matching package archive directly.
- Connector tests, `go vet ./...`, release builds, published checksum verification, and isolated MiMo lifecycle tests passed before publication.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
