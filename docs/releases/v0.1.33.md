# v0.1.33 - Claude Desktop telemetry and Hermes discovery

This stable release adds telemetry for Claude Desktop and improves discovery of existing Hermes profiles. [PR #40](https://github.com/GuanceCloud/obs-agent-connector/pull/40) · [PR #38](https://github.com/GuanceCloud/obs-agent-connector/pull/38)

## Changes

- Add the built-in `claude-desktop` target for local Code and Cowork on macOS, Linux, and Windows. It registers machine-level `Stop` and `SessionEnd` Hooks with administrator authorization through sudo on macOS and Linux or UAC on Windows.
- On Windows, stage the administrator helper in a protected directory under the user profile if Local AppData fails the staging checks.
- Show the installed Claude Desktop machine runtime version in `list` and `status claude-desktop`. These commands query the installed runtime offline, so the reported version can differ from the current CLI version.
- Label Desktop traces and metrics with `agent_runtime=claude-desktop` and distinguish Code from Cowork with `claude_surface=code` or `claude_surface=cowork`. Terminal Claude CLI sessions use `agent_runtime=claude`.
- Share a session-and-turn upload ledger across the Claude CLI and Desktop Hooks. Trace and metric checkpoints are recorded separately to avoid duplicate uploads when both Hooks see the same turn.
- Discover Hermes from an existing `config.yaml` or installed plugin in the resolved `HERMES_HOME` when the Hermes command is unavailable on PATH.

## Installation and upgrade

Install or replace the connector binary with `v0.1.33`. Run `obs-agent-connector install claude-desktop` for a new integration or `obs-agent-connector update claude-desktop` to refresh an existing machine registration using the account's existing telemetry settings. Run the commands as the account that uses Claude Desktop and complete the operating system's administrator approval. Start a new local Code or Cowork session to load the managed Hooks. Windows Cowork requires the Cowork service in the full Claude Desktop installer and a compatible Windows device. [Claude Desktop setup](https://github.com/GuanceCloud/obs-agent-connector/blob/v0.1.33/docs/plugins.md#claude-desktop)

The release includes six platform archives for AMD64 and ARM64, Shell and PowerShell installers, `latest.txt`, and `SHA256SUMS`.
