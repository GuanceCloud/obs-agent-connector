# obs-agent-connector v0.1.30-rc1

## Changes

- Added complete `CODEX_HOME` support for Codex installation, update, discovery, automatic Hook trust, runtime state, legacy configuration, Skill classification, and removal.
- Preserved `~/.codex` as the default when `CODEX_HOME` is unset.
- Kept connector-managed configuration and Hook logs under `~/.obs-agent-connector/codex` while Codex-owned files follow `CODEX_HOME`.

## Scope and validation

- Fixes Codex Hook installation in CI/CD environments where the operating-system user home and `CODEX_HOME` are different.
- Preserves unrelated Hooks, trust entries, authentication data, and existing runtime configuration during installation and removal.
- Regression tests cover custom `CODEX_HOME` installation, trust, discovery paths, runtime configuration and state, Skill source classification, and cleanup.
- The full Go test suite, `go vet ./...`, release build, pull-request CI, package smoke tests, and Windows Hook smoke tests passed before publication.
- This prerelease includes [PR #30](https://github.com/GuanceCloud/obs-agent-connector/pull/30).

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
