## Changes

- Fixed OpenClaw LLM timing by preferring native `model_call_ended` durations and otherwise using only unambiguous `llm_input` and `llm_output` boundaries.
- Removed fabricated 1 ms LLM and assistant durations. Calls without reliable timing are omitted while turn-level token usage is retained and marked as aggregate-only.
- Aligned assistant timing with the legacy OpenClaw plugin: when a reliable model completion boundary exists, the assistant span covers model completion through terminal run completion; otherwise it is emitted as a zero-duration terminal event.
- Improved full connector uninstall output by grouping results by Agent, including OpenClaw, and showing the affected Hook and legacy plugin paths with explicit removal status.
- Retained all v0.1.24-rc4 features, including standardized OpenClaw diagnostics, legacy plugin removal compatibility, and nonfatal Gateway restart after installation or update.

## Validation

Full Go tests, vet, build, Node bridge tests, pull-request CI, six-platform package smoke tests, and Windows Hook smoke tests passed. Timing regression coverage includes a 41.47-second run with a 40-second native LLM call and a 470-millisecond assistant finalization phase, unambiguous Hook boundaries, missing timing, and aggregate token preservation.

Live OpenClaw Gateway and native macOS/Windows OpenClaw runtime validation remain outstanding.
