# obs-agent-connector v0.1.26

## Changes

- Added `mimo` as a supported Agent with discovery and full external-plugin lifecycle commands: install, status, update, enable, disable, remove, and purge.
- Added MiMo Code path resolution for `MIMOCODE_HOME`, XDG configuration, and data directories across macOS, Linux, and Windows.
- Added the MiMo variant of `opencode-otel-plugin`, with isolated registration and removal that preserve authentication, providers, unrelated plugins, and telemetry configuration.
- Added support for exact GitHub plugin release URLs, allowing prerelease and pinned plugin validation without changing stable organization-based release resolution.

## Scope and validation

- MiMo Code 0.1.14 was product-tested with `xiaomi/mimo-v2.5`, including a two-step flow with a `read` tool call and structured tool response context.
- The compatible `opencode-otel-plugin v0.1.6` stable release is available from GuanceCloud.
- Connector lifecycle tests cover install arguments, platform paths, JSON/JSONC registration, status, enable, disable, update, remove, purge, and configuration preservation.
- The change was validated through two connector RCs. The full Go test suite, `go vet ./...`, release builds, checksum verification, and isolated packaged-installer validation passed before this stable release.
- Native MiMo execution was validated on macOS. Windows behavior is covered by path, argument, and PowerShell contract tests; native Windows product execution remains pending.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
