## Changes

- Aligned built-in OpenClaw traces and metrics with the GTrace AI semantic conventions.
- Added structured model input and output messages, system instructions, tool definitions, provider/model summaries, finish reasons, output type/kind, and content lengths when the host exposes them.
- Added native model start and tool start observations, preserved timestamped multi-call Hook windows, and omitted calls with missing or zero timing instead of fabricating 1 ms spans.
- Normalized tool commands and result status while retaining `captureContent=none` privacy behavior.
- Kept OpenClaw first-response-chunk timing on the LLM trace span without emitting a default first-chunk metric or labeling it as strict TTFT.
- Restricted `gen_ai.client.token.usage` metrics to attributable LLM usage. Turn-aggregate usage remains on `invoke_agent` for trace analysis without producing duplicate token metrics.
- Added standard Agent identity attributes to shared telemetry resources for built-in adapters.

## Validation

Full Go tests, vet, build, Node bridge tests, pull-request CI, six-platform package smoke tests, Windows Hook smoke tests, diff checks, and the repository language scan passed.

Regression coverage includes structured messages and tool responses, system/tool request context, timestamped terminal snapshots, unique and ambiguous native-call matching, real model/tool timing, missing and zero timing, aggregate-token metric exclusion, first-chunk metric exclusion, cancellation, privacy, retry behavior, installation, update, removal, and nonfatal Gateway restart failure.

Live OpenClaw Gateway and native macOS/Windows OpenClaw runtime validation remain manual acceptance checks.
