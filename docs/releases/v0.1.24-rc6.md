## Changes

- Added native CodeBuddy Code CLI JSONL transcript support while preserving the legacy IDE `index.json` plus `messages/` format (PR #13).
- Normalized messages and function calls/results in memory, with no conversion script or version-specific Hook configuration required.
- Deduplicated raw token usage by provider message ID, including parallel tool calls and repeated message snapshots. Incomplete records are retried; terminal assistant messages and tool results gate export.
- Retained all v0.1.24-rc5 changes, including the built-in OpenClaw adapter, observed model timing, assistant finalization timing, and plugin lifecycle improvements.

## Compatibility and validation

Both CodeBuddy formats use the same privacy filters, aggregate LLM timing, cancellation rules, and upload deduplication. Regression coverage includes equivalent legacy/JSONL turns and fingerprints, partial writes, malformed records, parallel tool calls, repeated usage, and Stop/SessionEnd replay.

The CodeBuddy change passed Linux CI, six-platform packaging, Windows Hook smoke tests, and local adapter race tests before integration. A native Linux CodeBuddy Code 2.148.0 session was replayed with matching source usage. Existing Mac-specific Codex discovery behavior can cause `TestRemoveCodexDryRunShowsLocalCleanupOnly` to fail when ChatGPT.app bundles a discoverable Codex binary; this also reproduces on the unchanged main branch.
