# v0.1.32-rc1 - Experimental Codex sandbox runtime bridge

This prerelease is for connector-side sandbox bridge acceptance. It is built
from the unmerged feature branch and does not promote the stable channel.
Related work: [issue #34](https://github.com/GuanceCloud/obs-agent-connector/issues/34).

## Changes

- Add OTLP/HTTP Protobuf Logs with an explicit Logs endpoint and gzip export.
  Sandbox LogRecords carry `source=agent_sandbox`.
- Add an opt-in internal NDJSON runtime bridge for sandbox identity/state,
  lifecycle evidence, and many-to-many OBS Trace associations.
- Add a bounded durable journal, event deduplication, restart recovery, persisted
  retry backoff, `Retry-After`, and explicit partial-rejection handling.
- Pin actual OBS Trace/Span identities across partial Trace/Metrics retries and
  recover confirmed tool associations without reopening completed Agent spans.
- Isolate sandbox queues and recovered associations by destination/authentication
  scope; preserve the existing Agent trace hierarchy and default Hook fail-open
  behavior.

## Validation and limits

Local validation covers the full Go test suite, `go vet`, native build, targeted
race tests, protocol wire fixtures, and synthetic loopback OTLP export. Tests
include delayed/cross-turn association, concurrent producers, replay/restart,
capacity exhaustion, receiver rejection, destination isolation, and Metrics
retry after successful Trace export. These checks do not establish native
sandbox lifecycle or live Guance acceptance.

**Stock Codex automatic sandbox collection is not implemented.** Source inspection
of Codex 0.162.1 identifies process lifecycle and executor telemetry but does not
establish a reliable sandbox instance ID or complete destruction evidence. The
bridge requires a separately integrated authoritative runtime producer. It is
disabled by default and is not automatically started or registered by installation.

Guance log-source mapping, sandbox inventory materialization, lifecycle history,
and bidirectional Trace navigation remain separate receiver/product acceptance
gates. Process/file/network auditing and resource Metrics are outside this RC.
Do not infer sandbox creation or destruction from tool/turn boundaries.

See the [configuration, event contract, and recovery limits](https://github.com/GuanceCloud/obs-agent-connector/blob/v0.1.32-rc1/docs/codex-sandbox-observability.md).

## Distribution

The release contains macOS/Linux AMD64 and ARM64 tarballs, Windows AMD64 and ARM64
ZIPs, installer scripts, RC version metadata, and `SHA256SUMS`. Use the versioned
GitHub prerelease artifacts and verify checksums before testing. This RC does not
update stable CDN pointers or the stable latest release.
