# obs-agent-connector v0.1.25-rc1

## Changes

- Added the OpenTelemetry `gen_ai.response.time_to_first_chunk` attribute to Codex `llm` spans, expressed in seconds.
- Preserved the existing `ttft` attribute in milliseconds for compatibility with current queries and dashboards.
- Extended Codex collector assertions and golden fixtures to cover fractional-second values, multi-step turns, Skills, usage, and subagents.

## Scope and validation

- The value is derived from the existing Codex model-request boundary and the first recorded response step. It is omitted when those timestamps do not form a valid boundary.
- This RC adds a Trace attribute only; it does not add a dedicated time-to-first-chunk metric.
- The full Go test suite, `go vet ./...`, release build, and Agent OTEL baseline validation passed before publication.
- This prerelease is built from [PR #19](https://github.com/GuanceCloud/obs-agent-connector/pull/19) for integration testing and does not merge the PR.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
