# obs-agent-connector v0.1.27

## Changes

- Added Pi 0.85.1+ as a built-in Agent with discovery, installation, status, update, enable, disable, removal, and purge support.
- Added a connector-managed Pi lifecycle extension and bounded Go worker. Terminal turns are exported only after `agent_settled`, so retries and queued continuations are not reported as completed early.
- Added Pi traces for agent turns, native LLM duration and client-observed TTFT, token and cache usage, Tool calls, high-confidence Skill identity, assistant output, and terminal status. The standard four Agent metrics are derived from the same spans.
- Added privacy-aware bounded snapshots, atomic queue writes, persistent signal-level retry, duplicate-terminal protection, and fail-open collection behavior.
- Added Pi Subagent visibility: the parent records the native `subagent` Tool call, while independently launched child Pi processes emit separate root traces without inferred cross-process parentage.

## Scope and validation

- Pi installation merges the managed extension into global settings without replacing unrelated extensions. Updates preserve runtime configuration, and removal deletes only connector-managed files and registration.
- Normal, Tool, Skill, single Subagent, parallel Subagent, and bounded-queue scenarios were product-tested on macOS ARM64 and validated in `v0.1.27-pi-rc1`.
- Parser and extension fixtures cover multi-LLM flows, TTFT, token and cache usage, cancellation, incomplete Tool suppression, content-free capture, Subagent summaries, disabled collection, upload deduplication, and partial-signal recovery.
- The full Go test suite, race tests for the Pi adapter, JavaScript extension tests, `go vet ./...`, and release builds passed before this stable release.
- Linux and Windows have build and contract-test coverage. Native Pi runtime loading on those platforms and production-backend validation remain open validation items.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
