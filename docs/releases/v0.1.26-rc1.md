# obs-agent-connector v0.1.26-rc1

## Changes

- Added `mimo` as a built-in Agent with `list`, `discover`, `install`, `status`, `update`, `enable`, `disable`, and `remove` lifecycle support.
- Added MiMo Code discovery through the `mimo` executable and its platform-specific configuration and data directories.
- Added native MiMo plugin installation with isolated `MIMOCODE_HOME`, XDG, JSON/JSONC registration, runtime configuration, and removal behavior.
- Updated the shared OpenCode plugin integration to install its MiMo entry point through `--variant mimo`.

## Scope and validation

- MiMo Code 0.1.14 was validated on macOS with `xiaomi/mimo-v2.5`, including a two-step model flow with a `read` tool call.
- The matching plugin RC records the first LLM user input, the tool request, and the subsequent `tool_call_response`; the test response was `TOOL_INPUT_CAPTURE_OK`.
- Plugin lifecycle tests preserved comments, provider/authentication settings, unrelated plugins, and telemetry configuration across install, status, enable, disable, update, remove, and purge.
- Connector unit tests, `go vet ./...`, release build checks, plugin tests, type checking, and packaged installer validation passed before publication.
- Windows behavior is covered by argument, path, and PowerShell contract tests; a native Windows execution test is still pending.

## Downloads

Packages are available for macOS, Linux, and Windows on AMD64 and ARM64. The release also includes `install.sh`, `install.ps1`, `latest.txt`, and `SHA256SUMS`.
