## OMP GTrace integration — RC2

- Includes the OMP native extension, built-in Go collector, lifecycle management, and parent-child Agent trace correlation introduced in RC1.
- Fixes native OTLP status for successful spans: all built-in collectors now emit `OK` instead of `UNSET`. Error spans continue to emit `ERROR`. This covers the shared Span builder and the independent Codex collector; external plugins are unchanged.
- Keeps bounded upload retries, single-file handoff, and temporary snapshot cleanup for OMP.

## Validation

- OMP and Codex status behavior was verified manually after the fix.
- Relevant collector tests, Protobuf status round-trip tests, and `go vet` passed.
- The local full test suite retains the existing `TestRemoveCodexDryRunShowsLocalCleanupOnly` failure caused by local Codex discovery.
- Windows and Linux OMP runtime behavior has not been verified end to end.

This is a prerelease for integration testing. It does not merge PR #14.
