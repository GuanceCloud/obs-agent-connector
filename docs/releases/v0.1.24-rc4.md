## Changes

- Aligned OpenClaw hook diagnostics with the shared JSONL envelope and standard hook, parsing, trace upload, and metric upload events. Added bridge and upload failure diagnostics without logging conversation payloads or raw bridge errors.
- Restored removal compatibility for legacy OpenClaw plugins, including legacy-only installations. Removal cleans known plugin directories, load paths, allowlist entries, and installation records while preserving unrelated plugins and legacy settings by default.
- Installation and update now attempt `openclaw gateway restart` after success, with a 20-second timeout. Restart failure produces a warning and does not fail or roll back installation.
- Retained all v0.1.24-rc3 features, including built-in OpenClaw telemetry and GenAI first response chunk timing.

## Validation

Full Go tests, vet, build, and Node bridge tests passed. Regression coverage includes duplicate/retry logging, log privacy and write failures, legacy-only removal, unrelated plugin preservation, and restart failure during installation and update. Live OpenClaw Gateway and native macOS/Windows runtime validation remain outstanding.
