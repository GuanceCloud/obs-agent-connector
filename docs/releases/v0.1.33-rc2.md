# v0.1.33-rc2 - Restore legacy desktop sandbox associations through shell snapshots

This prerelease updates [PR #35](https://github.com/GuanceCloud/obs-agent-connector/pull/35), which remains open and unmerged. It retains RC1's default-enabled sandbox observation and mainline Hermes fixes. The stable release is unchanged.

## Changes since RC1

- Preserve session-only metadata from a verified direct command child. Older desktop exec-server builds may provide CODEX_THREAD_ID without CODEX_TOOL_CALL_ID; these observations can use the existing unique-session/command association path rather than discarding all context.
- Recognize complete known Shell Snapshot V2 replay envelopes for Bash, Zsh and Sh, including descriptor and numbered-state-variable transports. The observer hashes the original command in memory, so a runtime-generated restoration script does not hide the matching Hook command. Arbitrary wrappers and malformed restoration scripts remain unmatched.
- Keep evidence levels explicit: native Tool IDs use native_process_tool_id/observed; session plus a unique command uses native_thread_command_digest/inferred. Conflicting identities, missing sessions and ambiguous commands remain unlinked. No command text, snapshot state or environment payload is persisted.
- Extend real-runtime acceptance to Snapshot V2 and legacy desktop metadata. Mark fixture telemetry explicitly and support optional forwarding to the configured receiver. Test cleanup verifies the private observer's process identity and waits for shutdown before deleting temporary state.

## Validation

The Snapshot V2 failure was reproduced against the actual bundled Codex Desktop 0.162.0-alpha.2 executable before the fix. After the fix, two concurrent sessions with identical commands associate with their own exported Tool Span and distinct Trace IDs. Both normal and Snapshot V2 paths pass against desktop 0.162.0-alpha.2, standalone CLI 0.163.0 and daemon 0.166.0. Legacy desktop associations are asserted as inferred; newer native Tool-ID associations remain observed.

Additional checks cover complete and malformed snapshot envelopes, session-only child metadata, namespace/owner/parent/start identity validation, context conflicts, command ambiguity, full Go tests, vet/build and targeted race tests.

## Upgrade and limits

Install the RC2 connector binary and run `obs-agent-connector update codex` to refresh lifecycle Hooks while preserving existing configuration and unrelated integrations. Reload existing Codex sessions as needed. Explicit sandbox opt-outs remain preserved.

Runtime initialization and snapshot-capture instances may have no Tool association. Full-access Tool commands may create no sandbox at all. Missing historical session/call evidence is not reconstructed, and an arbitrary lifecycle record is never attached to the nearest turn. Native Linux observation remains best-effort polling; this release does not add exact lifecycle clocks, kernel auditing or non-Linux native collection.

Actual cloud fixture acceptance and independent query results must be reported separately; an HTTP success response alone does not prove platform storage or Trace navigation.
