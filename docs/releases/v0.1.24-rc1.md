## Changes

- Embedded WorkBuddy telemetry into the connector's Go binary, eliminating the external plugin download and Node.js dependency.
- Added WorkBuddy command Hook registration, JSONL replay, tool timing, token usage, Skill detection, explicit subagent associations, background uploads, and signal-level retry.
- Added migration from the external WorkBuddy plugin while preserving legacy configuration and upload markers and removing only managed registration entries.
- Added `obs-agent-connector agents` to list supported Agents and platforms; removed the verbose Examples section from top-level help.
- Fixed plugin download-base resolution when the connector was installed from a GitHub release, avoiding invalid `/releases/download/agent_plugins` URLs.
- Retained all v0.1.23 changes, including Grok Build support and Windows Hook fixes.

## WorkBuddy migration

Run `obs-agent-connector install workbuddy` with this RC to register the built-in adapter. The installer no longer rejects installation solely because WorkBuddy or CodeBuddy is running.

Restart WorkBuddy before the next conversation to unload the previous plugin and load the managed Hooks. If WorkBuddy overwrites settings on exit, rerun installation while it is closed. Native macOS/Windows hot reload has not been validated; this RC does not promise restart-free activation.

WorkBuddy product support remains macOS and Windows. Managed configuration, logs, and state are stored under `~/.obs-agent-connector/workbuddy/`.
