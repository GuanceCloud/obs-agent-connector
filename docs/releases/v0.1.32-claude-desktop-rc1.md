## Claude Desktop machine Hooks

- `obs-agent-connector install claude-desktop` installs machine-level Hooks for local Code and Cowork on macOS, Linux, and Windows. The installation uses the OS authorization prompt and requires no Claude plugin import.
- `status`, `update`, and `remove claude-desktop` manage the same registration. Each session account uses its own OBS configuration. Claude Code and Desktop share upload state to deduplicate turns when both OBS Hooks are registered.
- The release contains x64 and ARM64 packages for all three operating systems.

## Install this RC

On macOS or Linux, run the standard installer from this release. `--binary-only` reuses the connector configuration already on the device.

```sh
obs_rc_base=https://github.com/GuanceCloud/obs-agent-connector/releases/download/v0.1.32-claude-desktop-rc1
obs_rc_setup=$(mktemp -d)
curl -fsSL "$obs_rc_base/install.sh" -o "$obs_rc_setup/install.sh" &&
  sh "$obs_rc_setup/install.sh" --download-base-url "$obs_rc_base" --binary-only &&
  obs-agent-connector version --offline &&
  obs-agent-connector install claude-desktop --capture-content none &&
  obs-agent-connector status claude-desktop
```

For a fresh connector configuration, use `--endpoint` and `--x-token` with the Shell installer. On Windows, download this release's `install.ps1` and pass the same base URL with `-DownloadBaseUrl`. Use `-BinaryOnly` with an existing OBS configuration, or `-Endpoint` and `-XToken` to set up a new one. Open a new terminal after installation if the shell still needs the updated PATH.

Start new local Code and Cowork sessions and send one synthetic request in each. In the Guance test workspace, verify one trace per `gen_ai_conversation_id` and check `claude_surface`. Repeat a Code turn with the legacy OBS `claude` registration also enabled to check deduplication. Run `obs-agent-connector remove claude-desktop` to remove the machine files after testing.

## Validation

The Go test suite passed on macOS ARM64 and in an isolated Linux ARM64 container. The Linux release binary passed an isolated machine installation, synthetic Hook export and replay, update, and removal test. Windows x64 and ARM64 builds and affected test cross-compilation passed. Native Desktop Hook loading and Guance ingestion still require acceptance on the target devices.
